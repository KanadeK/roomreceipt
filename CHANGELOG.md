# Changelog

All notable changes are documented here.

## 0.1.0 - 2026-08-09

- Added the full case, slot, single-import, and atomic CSV import workflow.
- Added EXIF capture metadata, image dimension, MIME, byte size, and SHA-256 recording.
- Added stable move-in and move-out pairing with deterministic pixel difference aids.
- Added coverage, metadata, duplicate, file-integrity, and stale-seal audit findings.
- Added case seals, deterministic ZIP bundles, and independent safe-path verification.
- Added printable dual-theme HTML reports.
- Added deterministic synthetic example data and a live GitHub Pages demo.
- Added local release gates, CI, CodeQL, Pages, tag release packaging, and repair documentation.
