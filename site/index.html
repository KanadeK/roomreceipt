A stable slot name connects move-in and move-out images. The difference image highlights pixels, not blame.

Evidence register

Repeatable pairing

Use the same slot key at move-out. Missing views remain visible instead of being guessed.

Independent verification

Verify a directory or portable ZIP. Changed bytes, missing members, duplicate names, and unsafe paths fail closed.

A narrow claim is a stronger claim.

Verification confirms that listed bytes still match a seal. It cannot establish capture time, authorship, legal admissibility, or whether a photo was edited before sealing.

roomreceipt verify bright-street-demo.roomreceipt.zip
verified 29 files: 0171...d9b

Build a case in minutes.

uv tool install "git+https://github.com/KanadeK/roomreceipt.git@v0.1.0"
roomreceipt init my-case --title "Move-in" --property "14 Bright Street"
roomreceipt import my-case move-in move-in.csv
roomreceipt seal my-case
roomreceipt bundle my-case
